## Discussion

Worst case is `gusset-taper-post-spine` at SF 208 — the plastic body is not remotely stressed. Both sections are floors: each idealizes only one reinforcing member (spine block alone; gusset pair alone) and ignores the rest (base plate, haunches, the other member), so the true composite SF is higher still. Both are flagged FEA-recommended only because the gusseted junction isn't a clean prism — not because margin is tight (SF 208, need 2). Treat FEA here as optional polish, not a gate. PLA one-liner: yield 50 vs PETG's 45 MPa, no derate either way (in-plane) — SF scales up ~11%, same conclusion.

**Governing limit is NOT the plastic — it's cleat grip.** This analysis only checks internal bending of the caddy body; it does not model the ~1.83 N·m moment reacting through the 28.2×40.1 mm socket against the actual cleat (pull-out, socket-wall peel, or cleat deformation/slip). With the caddy itself this overbuilt, cleat-socket interface strength is now the whole question — recommend a dedicated pull-out/bearing check (or physical test) at that interface before calling the design load-adequate. `review-printability.md` hasn't run yet on this v3 geometry; re-check layer-orientation calls here once it does.
